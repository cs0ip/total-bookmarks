# Total Bookmarks

Total Bookmarks помогает наводить порядок в закладках Firefox. Две панели позволяют одновременно просматривать разные папки, открывать сохранённые страницы и переносить закладки туда, где им удобнее находиться.

Обе панели автоматически обновляются по событиям создания, удаления, изменения и перемещения закладок Firefox. Серия событий объединяется в одно асинхронное чтение дерева; изменения во время чтения запускают следующий проход. Открытые папки и выделение сохраняются, пока соответствующие элементы остаются на месте. При удалении открытой папки панель возвращается к корню.

Иконки сайтов хранятся в IndexedDB с ключом `origin` (протокол, домен и порт). Компонент `Favicons.svelte` сразу показывает сохранённую иконку или стандартную иконку Firefox; загрузка и обновление выполняются фоновым скриптом. Папки используют стандартную иконку папки Firefox.

Иконка скачивается с `/favicon.ico`, а при его отсутствии — по ссылкам `rel="icon"` или `rel="apple-touch-icon"` на главной странице сайта. Загрузчик следует перенаправлениям и использует CDN, указанный самим сайтом. Относительные ссылки разрешаются с учётом конечного адреса страницы и `<base>`. Запросы не отправляют cookies и Referer; внешние сервисы поиска favicon не используются. Одновременно выполняется не более четырёх загрузок. Перед сохранением проверяется полное декодирование изображения.

Успешно загруженные иконки обновляются через календарный месяц. Если сайт недоступен, старая иконка сохраняется, повторная попытка выполняется не раньше чем через сутки. Ежедневное обслуживание через `browser.alarms` также удаляет записи, к которым интерфейс не обращался больше календарного года. Фоновое обновление не считается обращением. При запуске Firefox пропущенное обслуживание выполняется снова; для работы при закрытой вкладке менеджера нужны разрешения `alarms` и доступ к HTTP/HTTPS-сайтам.

После изменения манифеста или сборки перезагрузите временное дополнение в `about:debugging#/runtime/this-firefox`, затем обновите вкладку менеджера. Обновления одной вкладки недостаточно для применения изменений манифеста и фонового скрипта. Для загрузки иконок должен быть разрешён доступ расширения к сайтам в настройках Firefox. Кэш предыдущей версии загрузчика перепроверяется при следующем обращении к иконке, включая неудачные загрузки и повреждённые изображения.

Firefox может не выдавать автоматически доступ к сайтам, добавленный при обновлении расширения. В этом случае менеджер показывает кнопку **Разрешить загрузку иконок**, которая открывает стандартный запрос разрешения Firefox. После подтверждения отсутствующие иконки загружаются сразу; до подтверждения сетевые запросы не выполняются. Если Firefox использует старый манифест, менеджер предлагает перезагрузить расширение.

Проверка типов и сборка: `npm run build`. Интеграционные проверки иконок: после сборки запустить `python3 tests/run-site-icons.py` (нужны Python 3 и Firefox). Тесты запускают отдельный временный профиль и локальный HTTP-сервер и проверяют также отображение favicon в настоящем интерфейсе.
