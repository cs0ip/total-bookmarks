# Total Bookmarks

Total Bookmarks — двухпанельный менеджер закладок Firefox в духе Total Commander. Он помогает одновременно просматривать разные папки, открывать сохранённые страницы и переносить закладки между папками.

Изменения закладок автоматически появляются в обеих панелях. Открытые папки и выделение сохраняются, пока соответствующие элементы остаются на месте. При удалении открытой папки панель возвращается к списку всех закладок.

Иконки загружаются с сайтов и сохраняются для следующих открытий менеджера. Они автоматически обновляются раз в месяц; иконки, которые не использовались больше года, удаляются. Если сайт временно недоступен, сохраняется предыдущая иконка и загрузка повторяется позже. Для папок и сайтов без загруженной иконки используются стандартные иконки Firefox.

## Сборка

Нужны Node.js и npm. В каталоге проекта выполните:

```sh
npm install
npm run build
```

Готовое расширение находится в `dist/`. Отдельная проверка типов: `npm run check`.

## Установка и запуск

1. Откройте в Firefox `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение** и выберите `dist/manifest.json`.
3. Нажмите кнопку Total Bookmarks на панели браузера — менеджер откроется во вкладке.
4. Если появилась кнопка **Разрешить загрузку иконок**, нажмите её и подтвердите доступ к сайтам в запросе Firefox.

Временное дополнение нужно загружать заново после перезапуска Firefox.

## Работа с изменениями

Команда `npm run dev` автоматически пересобирает расширение при изменении исходников. Она не запускает сервер разработки.

После пересборки нажмите **Перезагрузить** у Total Bookmarks на странице `about:debugging`, затем обновите вкладку менеджера. Это также применит изменения разрешений и фонового скрипта.
