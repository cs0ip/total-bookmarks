# Рекомендации по проекту

## Назначение и источник идеи

- Двухпанельный менеджер закладок.
- Аналогом является Total commander, только интерфейс работает не с файлами, а с закладками браузера.

## Устройство проекта

- Лицензия проекта — MPL-2.0; официальный текст хранится в корневом `LICENSE`, SPDX-идентификатор указан в `package.json` и корневой записи `package-lock.json`. Vite включает `LICENSE` в обе сборки, поэтому файл также попадает в ZIP-дистрибутивы.

- Расширение использует Manifest V3 для Firefox и Chrome 148+, Svelte 5, Vite и Tailwind CSS 4. Tailwind подключён через `@tailwindcss/vite`; общие стили импортируются из `src/app.css` в `src/main.ts`.
- В `src/app.css` семейство и размер шрифта `body` заданы через переменные Tailwind вне `@layer`: Chrome добавляет собственные стили шрифта страниц расширений без слоя, которые перекрывают классы `font-sans`/`text-sm` в слое utilities. Не переносите это правило в `@layer base`; размер корневого шрифта и масштаб браузера остаются пользовательскими.
- `src/App.svelte` содержит страницу менеджера закладок. У кнопки на панели браузера нет всплывающего окна: `src/background.ts` открывает `index.html` во вкладке.
- Vite создаёт отдельные пакеты `dist/firefox/` и `dist/chrome/`, компилирует общий `src/background.ts` в `background.js` и копирует `public/icons/`. `build/manifest.firefox.json` хранит общие метаданные и Firefox-настройки; `build/manifest.ts` заменяет только различающиеся поля для Chrome. Манифест генерируется при каждой сборке. Оба фоновых скрипта используют ES-модули: Firefox — `background.scripts`, Chrome — `background.service_worker`.
- Исходная иконка приложения `public/icons/logo.svg` используется в Firefox-манифесте, заголовке менеджера и favicon вкладки. Chrome-манифест использует PNG 16/32/48/128 из того же SVG (SVG в manifest icons не поддерживается). После изменения логотипа запустите `python3 scripts/export-logo.py`; нужны системные librsvg, GdkPixbuf и GObject. Готовые PNG хранятся в репозитории; обычная сборка не требует этих библиотек.
- Firefox запрашивает `bookmarks`, `alarms`, `storage` и доступ к HTTP/HTTPS-сайтам. Chrome запрашивает только `bookmarks`, `storage`, `favicon`. CSP страницы расширения задан явно: `script-src 'self'; object-src 'self';`, чтобы загрузка с HTTP-сайтов не повышалась автоматически до HTTPS.
- Исходники и скрипты компонентов Svelte написаны на TypeScript. Подсказки для WebExtension API в IDE обеспечивают `@types/firefox-webext-browser` и `tsconfig.json`; глобальный объект `browser` не нужно импортировать в исходники.
- `npm run build` проверяет типы и собирает оба браузера; `build:firefox`/`build:chrome` собирают один. `npm run dev`/`dev:chrome` запускают сборку соответствующего браузера в режиме наблюдения, без сервера разработки. После пересборки перезагрузите расширение и его вкладку.

## Сборка и локальная установка

- Используются Node.js и npm.
- Установить зависимости: `npm install`.
- Проверить типы: `npm run check`. Собрать проект: `npm run build`.
- `npm run package` сначала полностью удаляет `dist/` через `scripts/clean.py`, затем пересобирает оба браузера и запускает `scripts/package.py` (Python 3, только стандартная библиотека). `package:firefox`/`package:chrome` предварительно удаляют только `dist/{browser}/` и `dist/packages/total-bookmarks-*-{browser}.zip`, затем собирают и упаковывают один браузер, сохраняя результаты другого. Очистка выполняется до проверки типов; ошибка очистки или сборки останавливает цепочку команд. Архивы находятся в `dist/packages/total-bookmarks-{manifest.version}-{browser}.zip`, с `manifest.json` в корне. В архив входит только соответствующий `dist/{browser}/`, а не весь `dist/`. Упаковка не подписывает расширения и не публикует их.
- Для временной установки: открыть в Firefox `about:debugging#/runtime/this-firefox`, нажать **Загрузить временное дополнение** и выбрать `dist/firefox/manifest.json`.

## Слой совместимости

- Общие WebExtension API вызываются через `browser`: Chrome 148+ предоставляет этот namespace и Promise API нативно. Дополнительный полифилл не нужен; минимальная версия явно указана в Chrome-манифесте. Не добавляйте различия браузеров в компоненты интерфейса.
- `src/platform/bookmarks.ts` нормализует дерево/дочерние элементы в общий `BookmarkNode`: выводит отсутствующий в Chrome `type` по URL, создаёт пустой `children` у папки и сохраняет Firefox-разделители. Адаптер создания убирает Firefox-поле `type` для Chrome. `moveBookmark()` принимает конечный индекс общего планировщика; в Chrome при перемещении вниз внутри одной папки увеличивает его на 1, поскольку Chromium считает индекс до удаления исходного элемента. Перед каждым перемещением читает актуальный индекс через `get()`, учитывая уже перемещённые элементы группы. `folderType` защищает саму системную папку Chrome от перемещения/удаления, но не её обычные дочерние элементы; `unmodifiable` защищает управляемые папки и элементы.
- Vite выбирает `@platform/icons` и `@platform/background` из `src/platform/{firefox,chrome}/` по `--mode`. TypeScript paths указывают на Firefox-реализацию; обе реализации проверяются компилятором. UI использует один контракт: `defaultIcons`, `iconOrigins`, `watchSiteIcon(url, onIcon)` с функцией отписки. Фоновые слушатели регистрируются синхронно при загрузке, без отложенных import.
- Firefox сохраняет загрузчик и IndexedDB-кеш в фоновой странице. Chrome использует локальный `runtime.getURL('/_favicon/')` с `pageUrl` и `size=32` и локальные SVG для папок/запасной иконки. У Chrome нет собственных сетевых загрузок иконок, таймеров обслуживания или IndexedDB; DOM-зависимый загрузчик не включается в service worker. Для страницы самого расширения `web_accessible_resources` не требуется.
- `CHROME_BIN=/path/to/chrome node tests/run-chrome.mjs` проверяет собранный Chrome-пакет через CDP в отдельном временном профиле (Chrome for Testing или Chromium). Проверяет загрузку service worker и UI, нативную схему закладок, favicon, переходы, команды, создание, удаление, фокус и сохранение языка. Общие сценарии `bookmark-drag.browser.js` также выполняются в Chrome настоящими событиями мыши CDP: перестановка, обе стороны, пустая папка, одинаковая папка, циклы, отмена и прокрутка. Эти проверки не подтверждают перехват зарезервированных сочетаний браузера: события клавиатуры внутри страницы синтетические.

## Автоматическое обновление закладок

- `src/App.svelte` подписывается на `browser.bookmarks.onCreated`, `onRemoved`, `onChanged`, `onMoved` и `onChildrenReordered`, если последнее событие доступно. Подписки и таймер удаляются при размонтировании компонента.
- События объединяются с задержкой 50 мс. Асинхронные вызовы `getTree()` выполняются последовательно; события во время чтения запускают следующий проход, чтобы не потерять изменения и не применить устаревший снимок поверх нового.
- Открытые папки и выделение сохраняются, пока элементы остаются на месте. Удаление открытой папки возвращает панель к корню, удаление или перемещение выделенного элемента из текущей папки выбирает первую доступную строку.
- Перемещение закладок обновляет интерфейс через события браузера. Кнопки ручного обновления нет.

## Открытие элементов

- В `src/components/BookmarkList.svelte` один клик по строке выделяет элемент, двойной клик открывает закладку в новой вкладке либо переходит в папку. Отдельных кнопок открытия у закладок и папок нет.
- Непустой список всегда имеет выделенную строку. Если выделение отсутствует или больше не входит в список, `BookmarkList.svelte` выбирает первую строку (включая `..`) и передаёт выбор через `onSelect`; полностью пустой список сбрасывает выделение. Это правило действует при загрузке, переходе в папку и обновлении дерева, включая появление элементов в пустом списке.
- Отметки чекбоксов закладок и папок независимы от текущей строки (`selectedId`). `BookmarkPanels.svelte` хранит для каждой панели отдельную карту `folderStates`: ID папки → `{ markedIds, focusedId }`. Состояния существуют в памяти до размонтирования компонента. Отметки восстанавливаются при каждом входе в папку; сохранённая строка с фокусом восстанавливается только при переходе из дочерней папки в её родителя. При входе в дочернюю папку выбирается первая строка, включая `..`. `openFolder()` сохраняет состояние перед переходом, `selectItem()` обновляет сохранённый фокус. При удалении сохранённой строки список выбирает первую доступную. Несколько закладок и папок можно отметить одновременно; обновление дерева сохраняет отметки по ID, а исчезновение элемента из текущего списка удаляет его отметку. Сохранённые отметки неоткрытой папки проверяются при следующем входе в неё. `BookmarkList.svelte` получает `markedIds` и передаёт новый набор через `onMarkedIdsChange`; состояние разных панелей независимо, даже если они открывают одну папку.
- `Bookmark.svelte` отображает закладку или папку с чекбоксом слева и отдельной кнопкой содержимого строки; интерактивные элементы не вложены друг в друга. Папки используют `Favicons folder` и подпись «Папка», закладки — иконку сайта и URL. `checked` и `onCheckedChange` управляют отметкой, `focused` и обработчики строки сохраняют навигацию и открытие. Чекбокс исключён из Tab-переходов; клик меняет отметку без открытия элемента и передачи фокуса чекбоксу. Отмеченная строка имеет мягкий голубой фон `#f1f6fd`; фон текущей строки `#ebe6fb` имеет приоритет. Разделители и `..` не получают чекбоксов; разделитель проверяется по `type` перед `url`, поскольку Firefox может возвращать ему служебный URL.
- `BookmarkPanels.svelte` хранит активную сторону (изначально левую); `BookmarkList.svelte` получает `active` и `onActivate`, экспортирует `focusSelected(reveal = true)`; `reveal = false` восстанавливает DOM-фокус без изменения прокрутки. Клавиатурный фокус строки синхронизирует выделение. При исчезновении выбранной строки активный список передаёт фокус новой выбранной строке; пустой или загружаемый список удерживает фокус на своём контейнере.
- Пока страница менеджера активна, фокус остаётся в одной из панелей, кроме открытого модального диалога создания, немодальной справки управления, окна «О программе» или меню выбора языка. Tab и Shift+Tab переключают панели на их выбранные строки; ArrowLeft передаёт фокус в левую панель, ArrowRight — в правую. Эти клавиши без Alt/Ctrl/Meta отменяют стандартное действие браузера, сохраняют выделение каждой панели и работают в пустых списках. Стрелка в сторону уже активной панели оставляет фокус на месте. Клик по заголовку или свободному месту панели активирует её. Нажатие основной кнопки мыши вне строк отменяет только стандартную передачу фокуса, сохраняя последующий клик и действия кнопки разрешений. Попытка передать фокус внешнему элементу возвращает его в активный список.
- Обработчики `focusin`, `focusout`, `mousedown` и `keydown` документа и `focus` окна устанавливаются в `BookmarkPanels.svelte` и удаляются при размонтировании. Восстановление после потери фокуса ждёт `tick()`, проверяет `document.hasFocus()` и отсутствие фокуса внутри панелей, чтобы не мешать другим вкладкам, интерфейсу браузера и нативным диалогам; при возвращении на страницу фокус восстанавливается в активной панели.
- Рамка назначается всему контейнеру строки через `focus-within`, чтобы охватывать и чекбокс, и содержимое. `outline-offset: 0` убирает белый зазор между рамкой и фоном строки. Кнопки строки используют `focus:outline-none`, исключая вторую рамку внутри общей. Рамка остаётся видимой, пока фокус внутри строки, независимо от использования мыши или клавиатуры. Цветовое выделение сохраняется отдельно в каждой панели.
- ArrowUp и ArrowDown без Alt/Ctrl/Meta выбирают предыдущую/следующую строку, включая `..` и разделители; фокус передаётся ей после обновления выделения через эффект активного списка. Удержание клавиши повторяет переход. На границах переход не выполняется, циклического обхода нет. Обработчик `keydown` списка отменяет стандартную прокрутку этих клавиш, включая пустой список; подписка устанавливается при монтировании и удаляется при размонтировании.
- Insert и Shift+ArrowDown переключают отметку текущего элемента и передают фокус следующей строке; Shift+ArrowUp переключает отметку текущего элемента и передаёт фокус предыдущей. Повторное выделение снимает отметку с уже отмеченного элемента. Home/End передают фокус первой/последней строке без изменения отметок; Shift+Home/Shift+End переключают отметку каждого элемента диапазона от текущей строки включительно до первой/последней включительно и передают фокус границе. `toggleRange()` обновляет набор отметок одним вызовом, даже если количество отмеченных элементов не изменилось, сохраняет отметки вне диапазона и пропускает `..` и разделители. На границах отметка текущей строки переключается без циклического перехода; повторные нажатия поддерживаются. Все сочетания без Alt/Ctrl/Meta отменяют стандартное действие, в пустом или загружаемом списке ничего не меняют. Прокрутка выполняется существующей логикой фокуса, а не обработчиком клавиш.
- Прокрутка следует за строкой с фокусом, независимо от способа её выбора. Программный фокус использует `preventScroll: true`; `keepRowVisible()` в `BookmarkList.svelte` сравнивает границы строки с видимой областью списка с учётом отступов и минимально изменяет только его `scrollTop`. Если строка уже видна, прокрутки нет; сама обработка ArrowUp/ArrowDown ничего не прокручивает. При обновлении или перестановке строк активный список также проверяет видимость строки с фокусом. Клик по чекбоксу, заголовку, разделителю или внешней кнопке сохраняет ручную прокрутку и не показывает заново старую строку; активация панели сама по себе также не прокручивает список. Клик по свободному месту внутри контейнера строки (`data-bookmark-row`) передаёт фокус кнопке этой строки.
- Enter на выделенной строке с клавиатурным фокусом выполняет то же действие. Обработчик отменяет стандартный клик кнопки и игнорирует повторные `keydown` при удержании Enter. Разделители не открываются.
- Пробел без Alt/Ctrl/Meta переключает отметку чекбокса текущей строки через `markItem()` в `BookmarkList.svelte`, сохраняя фокус и состояние папки. Повторные `keydown` при удержании игнорируются. Стандартное действие отменяется, чтобы не прокручивать список и не нажимать кнопку строки; для `..`, разделителей, пустого или загружаемого списка отметка не меняется.
- Backspace без Alt/Ctrl/Meta переходит в родительскую папку активного списка через `onOpenFolder(parentFolderId)`, независимо от текущей строки, включая пустые папки. Стандартное действие отменяется и в корне; без родителя или во время загрузки переход не выполняется. Повторные `keydown` при удержании игнорируются, чтобы одно нажатие не выводило сразу через несколько уровней. Выделение и фокус после перехода восстанавливаются обычной логикой списка.
- `BookmarkList.svelte` получает `parentFolderId` и добавляет первой строкой виртуальный элемент `..` со стрелкой `↑`, если родитель существует, включая пустые папки. Идентификатор `PARENT_FOLDER_ITEM_ID` экспортируется из модуля компонента; он используется только для выделения и не входит в дерево закладок или счётчик элементов. Переход выполняется через `onOpenFolder(parentFolderId)`.
- Выделение `..` сохраняется при обновлении дерева, пока текущая папка имеет родителя. Этот элемент нельзя переместить между панелями; в корне он отсутствует.
- Заголовок каждой панели показывает имя текущей папки, число элементов и «Выбрано: N» для отмеченных чекбоксами закладок и папок. Счётчик берётся из `markedIds` состояния текущей папки; при нуле его элемент отсутствует. Фокус строки не входит в этот счётчик. Видимых надписей «Левая панель»/«Правая панель» и кнопки перехода наверх в заголовке нет; панели различаются через `aria-label` для доступности. Переход к родителю выполняется через строку `..` в списке.
- Нижняя строка панели показывает путь к текущей папке с разделителем ` / `, исключая самый корневой узел (`rootId`, «Все закладки»). В самом корне путь пустой; при отображении подставляется неразрывный пробел (`\u00a0`), чтобы нижняя строка сохраняла ту же высоту, что и строка с путём. `src/App.svelte` строит `folderPath` по цепочке `parentId` в `nodesById`, поэтому переименование или перемещение предков обновляет путь через события дерева. Текущая папка всегда последняя. В `BookmarkPanels.svelte` переполнение обрезает начало пути с `...`, сохраняя конец; `dir="ltr"` у текста сохраняет порядок имён при `direction: rtl` у контейнера. Полный путь доступен через `title` и `aria-label`.

- Между панелями находится вертикальный разделитель шириной 12 px с линией 2 px; кнопок перемещения нет. `BookmarkPanels.svelte` хранит долю ширины левой панели (`leftShare`, изначально 50%) и меняет её при перетаскивании разделителя через Pointer Events с захватом указателя. Двойной клик по разделителю сбрасывает `leftShare` до 0.5, восстанавливая ширину 50/50. Каждая панель занимает минимум 20% доступной ширины. Отпускание, отмена или потеря захвата завершают перетаскивание; фокус остаётся в активном списке. Пропорции сохраняются при изменении размеров окна до размонтирования компонента. При ширине окна до 700 px панели расположены вертикально, разделитель скрыт.

## Полоса команд

- `BookmarkPanels.svelte` хранит сочетания клавиш вместе с конфигурацией команд и вызывает тот же `action`, что и кнопка, учитывая её `disabled`: Ctrl+ArrowUp/Down/Left/Right — соответствующее перемещение, Ctrl+A — всё, Ctrl+D — ничего, Ctrl+B — создать закладку, Ctrl+Shift+F — создать папку, Delete — удалить с подтверждением. Ctrl+N зарезервирован Firefox (`key_newNavigator`, `reserved="true"`) и не перехватывается страницей. Модификаторы должны точно соответствовать команде; удержание не повторяет команду. Для букв используется физический `KeyboardEvent.code`, чтобы сочетания работали при русской раскладке. Распознанные сочетания отменяют стандартное действие браузера даже при недоступной команде. В диалоге создания, справке управления и во время композиционного ввода обработчик не вмешивается; при перетаскивании события блокируются существующим обработчиком переноса.

- `src/components/CommandBar.svelte` — универсальная горизонтальная полоса кнопок в стиле Total Commander. Принимает `buttons: readonly CommandBarButton[]`; тип `CommandBarButton` экспортируется из модуля компонента и содержит `title: string` и `action: () => void | Promise<void>`. Кнопки отображаются слева направо в порядке конфигурации, нажатие вызывает соответствующий `action`; необязательный `disabled` блокирует недоступную кнопку. `symbol` задаёт символ вместо видимого заголовка, сохраняя название из конфигурационного `title` в `aria-label`; HTML-атрибут `title` не назначается, чтобы кнопки не показывали всплывающих подсказок; `separatorBefore` вставляет видимый разделитель `|` перед кнопкой. Необязательный `label` показывает подпись перед первой кнопкой, `labelBefore` — подпись группы перед конкретной кнопкой (после её разделителя). Кнопки имеют одинаковую высоту и компактную ширину без растягивания. Полоса занимает доступную ширину, при нехватке места прокручивается горизонтально. `icon` добавляет значок рядом с текстом; `imageSrc` показывает кнопку только с изображением, сохраняя `title` в `aria-label`; `popupId` и `expanded` задают доступную связь кнопки с немодальным окном. Компонент не задаёт конкретные команды; обработчики и обработка ошибок принадлежат вызывающему коду.

- `BookmarkPanels.svelte` подключает `CommandBar` под списками в формате «Переместить: ↑ ↓ ← → | Выделить: Всё Ничего | Создать: Закладку Папку | Удалить | ? Управление». Кнопки «Переместить вверх»/«Переместить вниз» используют отметки активной панели; «Переместить вправо» всегда переносит отметки левой панели в правую, «Переместить влево» — правой в левую, независимо от активной стороны. Если в исходной панели нет отметок, перемещается её фокусированная закладка или папка; при наличии отметок фокусированная неотмеченная строка не включается. `..` и разделители не перемещаются. Перемещение строки без отметки не создаёт отметку в назначении.
- `src/bookmarks/move.ts` строит последовательность перемещений по актуальным дочерним элементам папок. Отмеченные элементы сохраняют порядок списка и собираются в непрерывный блок: вверх — перед строкой, предшествующей первому отмеченному элементу, вниз — после строки, следующей за последним отмеченным элементом. На границах блок собирается у соответствующего края без циклического перехода. Между панелями блок вставляется после фокусированной строки назначения; при фокусе на `..` или пустом назначении — в начало. Если обе панели открывают одну папку, выбранные ID исключаются при определении позиции вставки. Порядок остальных элементов сохраняется.
- `App.svelte` проверяет возможность перемещения (корень Firefox, неизменяемые элементы, перенос папки в себя или потомка) и выполняет вызовы `browser.bookmarks.move()` последовательно. Во время группы чтения дерева не применяются к интерфейсу; события накапливаются и после завершения выполняется последовательное обновление дерева. `BookmarkPanels.svelte` блокирует команды на время операции, сохраняет отметки при перестановке, при переносе добавляет их к отметкам папки назначения и убирает из исходной папки. Активная сторона не меняется, фокус назначения сохраняется; если фокусированная строка исчезла из исходной папки, фокус получает строка на её прежней позиции, ограниченной последней оставшейся строкой; в пустой папке выбирается `..` либо контейнер без родителя. `App.svelte` сохраняет позиции перед переносом и применяет замену одновременно с новым деревом, до отображения списка. Сохранившаяся фокусированная строка остаётся выбранной, даже если её номер изменился; смена папки или фокуса пользователем во время операции не отменяется. При ошибке показывается сообщение, итоговое дерево обновляется, отметки переносятся только для успешно перемещённых элементов.


- Группа «Выделить: Всё Ничего» работает только с текущей папкой активной панели и сохраняет фокус и отметки другой панели. «Всё» отмечает все закладки и папки, исключая `..` и разделители; кнопка недоступна в пустом списке или когда всё уже отмечено. «Ничего» очищает отметки и недоступна при их отсутствии. После группы стоит разделитель `|`. «Удалить» удаляет отмеченные закладки и папки активной панели, а при отсутствии отметок — её фокусированную строку. Перед операцией `BookmarkPanels.svelte` открывает нативный `window.confirm()` с количеством выбранных строк (без подсчёта потомков) и пояснением об удалении содержимого папок. Отмена не меняет закладки, отметки или фокус; повтор после частичной ошибки показывает количество оставшихся отмеченных строк. `..`, разделители, корень Firefox и защищённые элементы не удаляются; папка удаляется вместе со всем содержимым через `browser.bookmarks.removeTree()`, закладка — через `remove()`.
- `ItemRequest` (`sourceId`, `ids`) в `src/bookmarks/move.ts` задаёт общий запрос к выбранным элементам; `MoveRequest` добавляет назначение и позицию вставки. `App.svelte` проверяет исходные элементы через `canRemoveItems()` перед удалением и перемещением. Общее состояние `mutating` блокирует команды и применение дерева до завершения группы. После удаления `refreshAfterMutation()` обновляет дерево; отметки удалённых элементов очищаются списками, фокус выбирает ближайшую позицию, открытая удалённая папка возвращает панель к корню. При частичной ошибке остаются отметки ещё не удалённых элементов и показывается сообщение об ошибке.
- `tests/bookmark-delete.browser.js` проверяет независимость очистки отметок, удаление закладок и папок с потомками, запрет повторной операции, сохранение фокуса, защиту корня и `..`, частичную ошибку и повтор удаления в изолированном профиле Firefox.


- Группа «Создать: Закладку Папку» открывает `CreateBookmarkDialog.svelte` — нативный модальный `<dialog>` с формой. Закладка требует названия и адреса, папка — только названия. Пустое после обрезки пробелов название и неверный адрес не отправляются. Отмена кнопкой или Escape ничего не создаёт и восстанавливает фокус исходной строки; поля сохраняются при ошибке, позволяя повторить создание. Во время отправки поля и кнопки заблокированы, Escape не закрывает незавершённую операцию.
- `CreateRequest` содержит `parentId`, `afterId`, `type`, `title` и необязательный `url`. `BookmarkPanels.svelte` запоминает активную панель и строку вставки при открытии диалога. `App.svelte` проверяет доступность папки через `canCreateItem()`, читает актуальных детей и вызывает `browser.bookmarks.create()` с индексом сразу после `afterId`; `..`, пустой список или исчезнувший ориентир задают индекс 0. В корне Firefox и защищённой папке создание недоступно. Обновление дерева выполняется общей последовательной очередью `refreshAfterMutation()`; отметки сохраняются, новый элемент не отмечен чекбоксом и получает фокус после закрытия диалога.
- Пока диалог открыт, обработчики панелей не перехватывают фокус, нажатия мыши, Tab и стрелки; `BookmarkList` не получает `active`. Все команды фона заблокированы, нативный `showModal()` удерживает взаимодействие внутри формы. `tests/bookmark-create.browser.js` проверяет отмену, валидацию, обе панели, середину/края/пустую папку, повтор после ошибки и сохранение отметок. `tests/run-site-icons.py` дополнительно проверяет реальные Tab и Escape в Firefox. Проверки конфликтов используют `EventUtils.synthesizeKey()` из окна браузера через chrome-контекст Marionette и контролируют окна, боковую панель и браузерный диалог закладок; действия WebDriver в content-контексте обходят обработку зарезервированных сочетаний и не подтверждают отсутствие конфликтов.


- «Управление» со значком вопроса открывает `KeyboardHelp.svelte` над CommandBar: немодальное окно без затемнения страницы, с ограниченной высотой и собственной прокруткой. Оно описывает все клавиши списка; сочетания команд и их описания берутся из конфигурации `commands`, чтобы справка соответствовала обработчикам. `popupOpen` (`help`/`about`/`null`) временно отключает удержание фокуса панелями и их клавиатурные команды, позволяя читать и прокручивать справку. Escape, уход фокуса, клик снаружи, повторный клик по кнопке и потеря фокуса окна закрывают справку; фокус возвращается в активную панель без прокрутки, если пользователь ещё не выбрал другую строку. Обработчики проверяют размонтирование перед отложенным закрытием.

- После справки управления расположен разделитель и кнопка с `icons/logo.svg`, открывающая `About.svelte`. Немодальное окно над полосой команд показывает две колонки (подпись и значение): «Автор» — Sergei Galushkin, GitHub — https://github.com/cs0ip/total-bookmarks. Ссылка открывается в новой вкладке с `noopener noreferrer`. Подписи переведены на все языки; у кнопки есть доступное название без всплывающей подсказки. Справка и окно «О программе» используют общее состояние `popupOpen`, одновременно открыто только одно окно. Escape, крестик, повторный клик по кнопке, уход фокуса, клик снаружи и потеря фокуса окна закрывают его и возвращают фокус в панель без прокрутки. Фокус между ссылкой и кнопкой закрытия внутри окна не закрывает его.

## Перетаскивание элементов

- `BookmarkPanels.svelte` управляет перетаскиванием мышью через Pointer Events. Нажатие на строку закладки или папки готовит перенос; движение на 6 px начинает его и захватывает указатель на контейнере панелей. Если исходная панель содержит отметки, переносится вся отмеченная группа в порядке списка, иначе — строка под мышью. Чекбокс, `..`, разделитель закладок и защищённые элементы не начинают перенос. Обычные клики и двойные клики сохраняют прежнее поведение.
- `BookmarkList.svelte` экспортирует `insertionAt(clientY)` и получает `dropMarkerTop`/`draggedIds`. Верхняя/нижняя половина строки задаёт вставку до/после неё; свободное место после списка — вставку в конец. `..` задаёт начало текущей папки и не меняет папку назначения. Линия вставки рисуется поверх списка без изменения высоты строк; переносимые строки становятся полупрозрачными, рядом с курсором показывается количество элементов.
- Перенос работает внутри панели и между панелями, включая одинаковую папку в обеих панелях и пустую папку назначения. Запрос использует `afterId` и существующий `planMoves()`; общий `performMove()` сохраняет порядок, отметки, фокус и обработку частичной ошибки для кнопок и мыши. Недопустимое назначение не имеет линии вставки. Корень Firefox, защищённые элементы и перенос папки в себя или потомка блокируются общей проверкой `canMoveItems()`.
- Возле верхнего/нижнего края списка перетаскивание прокручивает только этот список через `requestAnimationFrame` и пересчитывает линию вставки. Escape, отпускание вне допустимого списка, потеря указателя или фокуса окна отменяют перенос. Обновление дерева и смена исходной папки также отменяют активный перенос. Завершение освобождает захват и кадр прокрутки; последующий служебный клик не открывает строку. Все обработчики удаляются при размонтировании.
- `tests/bookmark-drag.browser.js` и `tests/run-site-icons.py` проверяют перенос настоящими движениями мыши Firefox: положение линии, группы папок и закладок, обе стороны, одинаковую папку, пустое назначение, запрет циклов, отмену и прокрутку у края.

## Языки интерфейса

- `src/locales/en.json`, `ru.json` и `zh.json` — единые словари английского, русского и китайского (упрощённого) языков. Ключи и параметры `{count}`/`{path}` должны совпадать; тип `TranslationKey` выводится из английского словаря. Пользовательские названия закладок и папок не переводятся.
- `src/i18n.ts` предоставляет реактивные Svelte stores `locale` и `t`, а также `setLocale()`. Компоненты используют `$t(key, params)`; ошибки хранят ключ или флаг, чтобы смена языка обновляла уже показанное сообщение. Логи и исключения остаются на английском.
- До монтирования интерфейса `main.ts` ожидает `initializeLocale()`: сохранённый выбор читается из `browser.storage.local` (`total-bookmarks:locale`), при его отсутствии используется `browser.i18n.getUILanguage()`. Прежний выбор из `localStorage` однократно переносится в хранилище расширения; после успешного переноса старый ключ удаляется. `setLocale()` немедленно обновляет интерфейс и последовательно сохраняет изменения через `storage.local.set()`, чтобы быстрые переключения не перезаписали последний выбор устаревшим. Настройка сохраняется при закрытии вкладки и перезапуске браузера; ошибки чтения и записи логируются на английском. Региональные варианты `ru-*` и `zh-*` используют соответствующий словарь; прочие локали получают английский. Смена языка обновляет `html[lang]`, заголовок и интерфейс без перезагрузки и сброса состояния панелей.
- `LanguagePicker.svelte` показывает кнопку с глобусом справа в заголовке и немодальное меню с родными названиями языков. Стрелки/Home/End перемещают фокус, Enter выбирает язык; Escape, уход фокуса, клик снаружи и потеря фокуса окна закрывают меню. `externalPopupOpen` временно отключает удержание фокуса и горячие клавиши панелей; закрытие возвращает фокус без прокрутки. В `focusout` проверяется `relatedTarget`: переход между пунктами меню не закрывает его, поскольку Firefox может выполнять микрозадачи до обновления `document.activeElement` при нативном клике. Интеграционные проверки выбора языка используют настоящие клики по пунктам меню, включая переход с английского на русский.
- Vite генерирует `dist/{firefox,chrome}/_locales/*/messages.json` для описания расширения и подсказки кнопки браузера из тех же словарей. В манифесте `default_locale: "en"`; метаданные выбирает браузер по своей локали, язык страницы можно изменить вручную.
- `npm run test:i18n` проверяет полноту словарей, параметры, автоматический выбор, восстановление в новой сессии, миграцию, порядок записей и недоступное хранилище. `tests/locales.browser.js` проверяет живое переключение, меню, диалоги, справку и сохранение состояния в изолированном Firefox вместе с остальными интеграционными проверками.

## Хранилище иконок

Следующие правила загрузки и обслуживания относятся к Firefox. В Chrome иконками управляет встроенный кеш браузера.

- `src/components/Favicons.svelte` сразу показывает сохранённую иконку или стандартный ресурс Firefox: `chrome://global/skin/icons/defaultFavicon.svg`; папки используют `chrome://global/skin/icons/folder.svg`.
- Загрузка и обслуживание выполняются фоновым скриптом. Сообщения `site-icons:get` запрашивают иконку, `site-icons:updated` уведомляют открытые страницы об успешном обновлении.
- `src/icons/store.ts` использует IndexedDB `total-bookmarks-site-icons`, версия 1, хранилище `icons` с ключом `origin` (протокол, домен, порт) и индексами `lastAccessedAt` и `nextRefreshAt`. Изменение записи выполняется в одной транзакции, чтобы обновление не затирало время последнего обращения.
- `src/icons/download.ts` сначала запрашивает `/favicon.ico`, затем ищет `rel="icon"` или `rel="apple-touch-icon"` на главной странице. Разрешены перенаправления и CDN, указанные самим сайтом; относительные ссылки учитывают конечный URL страницы и `<base>`. Внешние сервисы поиска favicon не используются, cookies и Referer не отправляются.
- Одновременно выполняются не более четырёх загрузок; запросы одного origin объединяются. Ограничения: 256 КиБ на иконку, 1 МиБ на HTML, 10 секунд на отдельный запрос или декодирование. Перед сохранением проверяется полное декодирование изображения.
- Успешная загрузка назначает обновление через календарный месяц; ошибка сохраняет старую иконку и назначает повтор через сутки. Ежедневное обслуживание `site-icons:maintenance` через `browser.alarms` сначала удаляет записи без обращений больше календарного года, затем обновляет просроченные. Фоновое обновление не считается обращением.
- Обслуживание также запускается при старте Firefox и установке расширения. Отсутствующий ежедневный таймер создаётся при запуске фоновой страницы, поскольку таймеры Firefox не сохраняются после перезапуска браузера.
- `downloadVersion` позволяет перепроверить старый кеш при обращении, включая повреждённые изображения и неудачные загрузки предыдущей версии.
- Доступ к сайтам из обновлённого манифеста может оставаться невыданным. Интерфейс проверяет разрешения и запрашивает их непосредственно из обработчика нажатия. До выдачи доступа запросы не выполняются и не откладывают следующую попытку; `permissions.onAdded` запускает повторную загрузку отсутствующих иконок.
- После сборки обновления страницы недостаточно для применения изменений манифеста и фонового скрипта: нужно перезагрузить временное дополнение, затем вкладку менеджера.

## Проверки

- `npm run check` проверяет типы; `npm run build` включает эту проверку и создаёт `dist/firefox/` и `dist/chrome/`. `npm run test:platform` после сборки проверяет нормализацию закладок, параметры создания, защищённые папки, URL favicon, манифесты, PNG и отсутствие DOM-загрузчика в Chrome worker.
- После сборки `python3 tests/run-site-icons.py` запускает интеграционные проверки иконок и событий закладок в отдельном временном профиле Firefox с локальным HTTP-сервером. Нужны Python 3 и Firefox; пользовательские закладки не изменяются.
- Тестовая страница подключает CSS сборки и классы `body` из `dist/firefox/index.html` до монтирования интерфейса, чтобы проверки видимости и прокрутки выполнялись с настоящими стилями.

# Логи

Все записи в лог должны быть на английском языке.

- Правило относится к сообщениям `console.*` и текстам создаваемых кодом исключений. Пользовательские сообщения интерфейса переводятся на выбранный язык и не должны использоваться как текст логов.
- Логи иконок пишутся в консоль фонового скрипта, доступную через **Inspect / Исследовать** у расширения в `about:debugging`, а не через F12 вкладки менеджера.
- Сообщения `console.info` с префиксом `[Favicons]` отмечают запуск и завершение пакетной очистки, обновления и повторной загрузки, а также успешное сохранение и удаление каждой иконки с её `origin`.
- Завершение содержит `durationMs` (миллисекунды, измеренные через `performance.now()`); обновление также содержит `count` (число запланированных записей). Завершение логируется даже при пустом пакете, при ошибке используется `console.error` с продолжительностью и причиной. Завершение обновления ожидает все запущенные работники, даже если один из них завершился с ошибкой.
- Удаление логируется только после успешного завершения транзакции IndexedDB, загрузка — после сохранения. Чтение иконки из кеша не логируется.
